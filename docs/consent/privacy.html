job-agent – Privacy Policy

Last updated: 22 November 2026

job-agent is a personal tool built and used only by Ahmed Khater to manage his own job applications. It is not offered to anyone else. This page explains what it does with Google user data.

Data accessed

  • Gmail, read-only (gmail.readonly): job-alert emails under one label (for example from LinkedIn), to find job postings; and a check of the Sent folder for a specific address, so the same employer is not contacted twice.
  • Gmail, compose (gmail.compose): creating draft application emails (with the owner's CV and cover letter attached) in the owner's own mailbox, and a daily summary email sent only to the owner's own address.

The tool does not delete, archive, label or forward email, and does not change any Gmail settings.

How the data is used and stored

  • Data is processed on the owner's own computer and stored there in a local database.
  • Text from job postings (not personal emails) may be sent to an AI model, through the owner's own Claude account, to extract job details and tailor the owner's application. No other Gmail content is sent.
  • The data is not sold, shared with third parties, or used for advertising.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the tool's local data folder removes everything it stored.
